# Deep Learning

This repository documents my journey of learning and understanding Deep Learning through concise theoretical summaries and practical coding implementations.

Each topic is organized into:

- **Theory:** A one-page summary covering key concepts, mathematical intuition, and important formulas.
- **Code:** Practical implementations using Python and relevant deep learning libraries.
- **Examples:** Simple experiments and demonstrations to reinforce understanding.

## Goals
- Build a strong foundation in deep learning concepts.
- Simplify complex topics into easy-to-review notes.
- Connect theoretical knowledge with practical implementations.
- Maintain a structured and accessible learning resource.

This repository serves as both a personal learning journal and a reference for anyone exploring deep learning.

**Learn the theory. Understand the math. Implement the concepts.**
